\section{Conclusion}
CriterionLens demonstrates a reproducible, evidence-oriented pipeline for criterion-level trial screening with small instruction models, together with explicit inference implementations and a locally hosted demonstration. The results are limited to a single public annotation source and a small patient-disjoint evaluation. Further work should test additional cohorts, improve annotation review, and optimize inference with measured rather than assumed benefits. Any clinical use would require substantially broader validation, governance, and oversight.
